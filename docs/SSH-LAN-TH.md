# SSH LAN — คู่มือสั้น

## เริ่มใช้

1. สร้างไฟล์โปรแกรมครั้งแรก: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-launcher.ps1`
2. ดับเบิลคลิก **`SSH LAN.exe`** (หรือรัน `scripts\app.ps1` ตรงๆ)
3. เครื่องที่จะ **รับ SSH**: ติดตั้ง *OpenSSH Server* ใน Windows ก่อน แล้วกด **เปิดใหม่แบบผู้ดูแล** → เลือกวงที่อนุญาต → **เปิดรับ SSH**
4. เครื่องที่จะ **เชื่อมต่อ**: กดปุ่มหลัก (ตั้งเครื่องนี้ให้เชื่อมต่อ) ครั้งเดียว

โปรแกรมเลือกบทบาทให้เอง: เครื่องที่มีบริการ OpenSSH Server คือเครื่องรับ ที่เหลือคือเครื่องเชื่อมต่อ

## ปุ่มบนเครื่องรับ SSH

- **เปิดรับ SSH** เปิดบริการ, อนุญาตพอร์ต 22 เฉพาะวงที่เลือก, ปิดรหัสผ่าน ใช้กุญแจเท่านั้น
- **ทดสอบการเชื่อมต่อ** ตรวจบริการ พอร์ต และไฟร์วอลล์
- **เพิ่มกุญแจเครื่องอื่น** คัดลอก public key ของเครื่องนั้นไว้ใน Clipboard แล้วกดปุ่มนี้
- **อัปเดตสถานะ** รีเฟรช IP และสถานะบริการ
- **ปิดการรับ SSH** หยุดบริการและลบกฎไฟร์วอลล์

## ตั้งเลข IP คงที่

ช่องเลข IP จะใส่เลขปัจจุบันให้ก่อน พิมพ์เลขเต็ม (`192.168.1.50`) หรือเฉพาะตัวท้าย (`50`) แล้วกด **ตั้งเลข IP คงที่**

- โปรแกรมตรวจว่าเลขอยู่ในวงเดียวกัน ไม่ใช่เลขของเราเตอร์ และไม่มีเครื่องอื่นใช้อยู่ ก่อนเปลี่ยนจริง
- ถ้าเปลี่ยนไม่สำเร็จ จะสลับกลับเป็น DHCP ให้เอง เครื่องไม่หลุดจากเครือข่าย
- กด **คืนเป็น IP อัตโนมัติ** เมื่ออยากกลับไปใช้ DHCP
- การตั้งแบบนี้ล็อกเลขที่ตัวเครื่อง เราเตอร์ยังแจกเลขเดียวกันให้เครื่องอื่นได้ ควรเลือกเลขนอกช่วงที่เราเตอร์แจก หรือจองเลขไว้ที่เราเตอร์ด้วย

## IP ของเซิร์ฟเวอร์เปลี่ยน

บนเครื่องเชื่อมต่อ กดปุ่มหลักอีกครั้ง สคริปต์จะหาเซิร์ฟเวอร์เอง: ลอง IP ที่เคยบันทึกไว้ก่อน ถ้าไม่เจอจะสแกนวง LAN ของเครื่องนี้หาเครื่องที่เปิดพอร์ต 22 และเลือกเครื่องที่กุญแจของคุณเข้าได้ แล้วอัปเดต `~/.ssh/config` ให้ รองรับทุกช่วง IP ในบ้าน (`10.x`, `172.16-31.x`, `192.168.x`)

## Linux

```bash
chmod +x scripts/ssh-lan/ssh-lan.sh && scripts/ssh-lan/ssh-lan.sh
```

## ตั้งค่า

ไฟล์ `%LocalAppData%\Ssh-Lan-Prime-Studio\config.json` (ไม่มีค่าของเครื่องใครฝังในโค้ด):

- `hostAlias` ชื่อที่ใช้ใน `~/.ssh/config` (ค่าเริ่มต้น `ssh-lan`)
- `identityFile` ชื่อไฟล์กุญแจใน `~/.ssh` (ค่าเริ่มต้น `id_ed25519_lan`)
- `serverUser` ชื่อผู้ใช้ที่ล็อกอินเข้าเซิร์ฟเวอร์ (ค่าเริ่มต้น ชื่อผู้ใช้ปัจจุบัน)
- `serverHost`, `serverIpSearch` ชื่อ/IP ของเซิร์ฟเวอร์ที่อยากให้ลองก่อน (ไม่ต้องใส่ก็ได้)
